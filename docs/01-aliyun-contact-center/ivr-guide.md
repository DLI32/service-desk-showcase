# 阿里云云联络中心 IVR 搭建指南

来源：S1、S2，见 [来源表](../SOURCES.md)。规格稿是目标，复盘是最终实现。已实测的是精简中文流程，不是完整双语流程。

## 前置准备

使用 `<ALIYUN_ACCOUNT>` 开通演示实例 `<INSTANCE_ID>`，完成平台要求的服务授权。准备四个技能组：新问题、进度查询、密码问题、其他问题；每组包含可上线坐席。呼入与白名单只在私有控制台管理，本文统一用 `<TEST_NUMBER>` 与 `<PHONE>` 表示。

历史体验环境有一次性白名单、通话总量及实例重建限制；规格稿关于“填满才可提交”的说法后来被修正为建议与上限，不能据此当作提交硬条件。开通前确认当时规则与所需测试人员。

## 中文最小流程：已实拨四路

```text
开始 → 收号（欢迎语+业务菜单） → 按键分支
                               ├─ 1 → 新问题转人工 → 结束
                               ├─ 2 → 进度查询转人工 → 结束
                               ├─ 3 → 密码问题转人工 → 结束
                               ├─ 4 → 其他问题转人工 → 结束
                               └─ 其他 → 回收号重听
```

最终模型为 8 个节点、25 条连线。欢迎语与菜单合并，去掉重复转接提示，排队音由转人工节点承担。

收号原文：

> 欢迎致电IT服务台。新问题请按 1，查询已有问题的进度请按 2，密码问题请按 3，其他问题请按 4。

历史配置：固定一位按键、收号循环两次、超时十秒；转人工采用分配、最先可用坐席，排队背景音统一为内置默认排队音乐。优先级、队列容量和超时应按演示负载设定，不照搬成生产策略。

## 双语目标话术：未完整上线

一级语言选择：

> 欢迎致电IT服务台。Thanks for calling IT Support. 普通话请按 1，For English, press 2.

中文二级菜单：

> 新问题请按 1，查询已有问题的进度请按 2，密码问题请按 3，其他问题请按 4。

英文二级菜单：

> For a new issue, press 1. To check the status of an existing issue, press 2. For password issues, press 3. For other issues, press 4.

两种语言均按四项业务落到相同技能组。扩展时在中文骨架前加语言收号与分支，再逐路增加英文节点。

| 用途 | 中文原文 | 英文原文 |
|---|---|---|
| 无效按键 | 您按的键无效，请重新选择 | Invalid option, please try again. |
| 转接提示 | 正在为您转接，请稍候。 | Please hold while we transfer your call. |
| 无坐席提示 | 现在坐席全忙，请稍后再拨。 | All agents are busy. Please try again later. |

规格建议超时重播一次后转其他问题；最终中文方案的其他分支回收号重听。两者不能混称同一已验证策略，无坐席与非工作时间出口也要单独设计。

## 搭建顺序

1. 建最小骨架并发布，再补业务支路；预期外的校验错误先解决再继续。
2. 节点逐个创建，每个出口只连一次；改线先删除旧线，避免重复出口。
3. 悬停端口后完整拖至目标输入口。回线难拖时临时移动目标节点，连好后移回。
4. 每段保存，看成功提示，退出重开核对出口，再发布验证。画布有线不能证明保存模型中有线。
5. 发布成功后绑定测试号码，重载号码管理页并回读绑定。
6. 坐席工作台切为在线，用受控白名单设备实拨。

历史最小实验中，转人工的成功、失败、超时、队列溢出四个功能出口必须接线，用户挂机与排队终止可留空。这是当时环境的实测结论，不是本次确认的通用平台规范。

## 排错与验收

- 大流程发布失败：从可发布最小流程逐步增量；不要在不可信模型上反复重拖。
- 同一节点持续报错：检查重复出口；曾有节点的六个出口重复成两组。
- 保存无反馈：重开编辑器，确认保存提示与发布状态；旧标签页可能静默失效。
- 克隆后节点变少：可能只保留可达节点，不能用克隆文件充当完整备份。
- 四路验收：分别按键，核对技能组及坐席实际接续，再记录时间和结果。

当时四路均实拨通过；错键回路仅核验模型，未实拨；英文完整四路未交付；无免拨模拟入口是当时控制台观测。后续测试应补错键、超时、无坐席、非工作时间和挂机场景。
